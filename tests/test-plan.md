# 测试计划

## 基础功能

- 验证 ADC/传感器读数、温度换算和滤波效果。
- 验证 PWM 占空比可按命令变化，且系统上电和复位时默认关闭。
- 验证按键设定、OLED 显示和 UART 上报。

## 温控性能

记录不同目标温度与环境条件下的升温时间、最大超调量、稳态误差和温度波动范围。每次修改 PID 参数均保存对应的测试记录。

## 故障注入

- 模拟温度传感器断线与短路。
- 模拟温度超过软件上限。
- 模拟通信中断和任务异常。
- 确认每个故障都会关闭 PWM、显示故障码并通过 UART 上报。

## 记录格式

建议 UART 每秒输出：时间戳、目标温度、实际温度、PWM 占空比、系统状态和故障码。使用 `tools/` 中的后续脚本或上位机绘制曲线。
