# 基于 STM32 与 FreeRTOS 的智能温控加热控制器

> 一个用于学习嵌入式软件、温度采样、闭环控制与安全保护的个人项目。

本仓库是独立实现的通用温控控制器，不包含任何实习单位的原理图、PCB、源码、BOM、型号参数或测试数据。

## 项目目标

使用 STM32 读取温度传感器数据，通过 PWM 控制加热负载，实现稳定恒温；系统采用 FreeRTOS 管理采样、温控、通信、显示与故障保护等并发任务。

## 功能规划

- NTC + ADC 温度采样、温度换算与滤波
- PID 闭环温控与 PWM 功率输出
- OLED 显示与按键设定目标温度
- UART 数据上报，便于上位机绘制温度曲线
- 过温、传感器断线/短路、加热异常等保护
- 基于 FreeRTOS 的任务、队列、事件标志组和互斥锁练习

## 系统架构

```text
温度传感器 -> ADC / I2C -> 采样与滤波 -> PID 控制 -> PWM -> 功率驱动 -> 加热负载
                                      |             |
                                      |             +-> 故障保护与关断
                                      +-> 显示 / 按键 / 串口日志
```

详细的软件架构见 [docs/architecture.md](docs/architecture.md)。

## 开发里程碑

1. 完成 ADC 采样、NTC 温度换算与串口输出。
2. 完成 PWM 驱动和开环加热测试。
3. 接入 FreeRTOS，拆分采样、温控、显示、通信和保护任务。
4. 实现 PID，并记录升温、超调、稳态误差等数据。
5. 完成故障注入测试与演示视频。

## 安全说明

软件保护仅用于学习与功能验证。实际加热设备还应配置与主控软件独立的硬件保护措施，例如保险丝、热熔断器或独立温控开关；未完成硬件安全设计前，不应接入高功率负载或无人值守运行。
